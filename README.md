# Bunko downloadable library

150 complete multilingual editions of public-domain classics, served as small JSON chapters with ruby readings and reviewed text-free covers. This repository is the content backend for [Bunko](https://lachlan.lazying.art/Bunko/); adding a book does not require a new app build.

## Publish a book

Use [Library management](https://lachlan.lazying.art/Bunko/admin/) to upload a prepared folder as a pull request, or add it under `books/<id>/` with Git. See the [publishing guide](https://github.com/lachlanchen/Bunko/blob/main/docs/library-publishing.md) for the schema and exporter.

Every bundle has `meta.json`, `rights.json`, compact chapter JSON and an optional cover. The owner confirms the final translations were generated by Codex; clearance checks the original author and work. See the [edition audit](https://github.com/lachlanchen/Bunko/blob/main/docs/catalogue.md). Modern reference filenames alone do not place a generated translation on hold.

```sh
python3 -m unittest discover -s tools -p 'test_*.py'
python3 tools/catalogue.py --write
```

The library workflow validates every chapter and rights record on pull requests. After merge it regenerates `reader-index.json`. Check the workflow before merging. Do not manually edit the derived index. Set `rights.status` to `hold` to remove a book from the catalogue. Keep old content-addressed chapters for readers with cached metadata.

Schema 1 remains compatible with installed Bunko 1.0.0 readers. Raw GitHub is the primary origin and jsDelivr is the fallback. New reader builds add image covers and automatic in-place catalogue refresh; content updates themselves need no binary.

Cover art contains no titles or lettering. The reusable original landscape and its generation record are under `assets/`. The app renders accessible titles separately. Book payloads belong here, never in the app repository.

Public-domain status can vary by territory. The audit records the original-author basis and owner declaration; it is not a worldwide legal certification. To report a data or rights problem, [open an issue](https://github.com/lachlanchen/bunko-books/issues/new).
