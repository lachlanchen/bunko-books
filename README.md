# Bunko Books

*The open, downloadable library behind Bunko.*

[![Reader](https://img.shields.io/badge/Open-Bunko-303F68?style=for-the-badge)](https://lachlan.lazying.art/Bunko/) [![Sponsor](https://img.shields.io/badge/GitHub-Sponsor-EA4AAA?style=for-the-badge&logo=githubsponsors)](https://github.com/sponsors/lachlanchen)

This repository hosts 150 complete editions of public-domain classics as compact JSON chapters with ruby readings and reviewed text-free covers. Bunko downloads only the chapters a reader opens and caches them offline. The app lives in [Bunko](https://github.com/lachlanchen/Bunko); adding an approved book here does not require a new app build.

[![Text-free illustrated cover](assets/classics-clean-2026-09-23.png)](assets/classics-clean-2026-09-23.png)

## Inside the library

| Path | Description |
| --- | --- |
| [`books/`](books/) | Published book folders: metadata, rights and chapter files |
| [`reader-index.json`](reader-index.json) | Derived catalogue used by the reader |
| [`tools/`](tools/) | Validator, catalogue builder and tests |

## Publish and validate

Use [Library management](https://lachlan.lazying.art/Bunko/admin/) to prepare a book pull request, or edit `books/<id>/` in Git. Read the [publishing guide](https://github.com/lachlanchen/Bunko/blob/main/docs/library-publishing.md) before adding files. The workflow checks every chapter and rights record, then regenerates `reader-index.json` after merge; do not edit that index by hand.

```sh
python3 -m unittest discover -s tools -p 'test_*.py'
python3 tools/catalogue.py --write
```

## Rights and compatibility

Each bundle needs `meta.json`, `rights.json` and compact chapter files; a reviewed text-free cover is optional. The [edition audit](https://github.com/lachlanchen/Bunko/blob/main/docs/catalogue.md) records the original-work basis. The owner confirms final translations were generated by Codex. Keep old content-addressed chapters for cached readers. Public-domain status can vary by territory.

## Corrections

To report missing text, a metadata error, a cover problem or a rights concern, [open a book issue](https://github.com/lachlanchen/bunko-books/issues/new). The catalogue audit is a documented review, not a worldwide legal certification.
